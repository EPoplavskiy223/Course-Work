# Курсовая работа
## Проект 1. Приложение для анализа банковских операций (Сервисы)

### Как работает приложение: 
* В модуле [main.py](src/main.py) собраны все функции из [services.py](src/services.py) уже с конкретными параметрами. 
* В модуле [services.py](src/services.py) есть запуск функций с выбором пользовательских параметров.
* в модуле [views.py](src/views.py) можно запустить отдельно страницу 'Главная'

## Как пользоваться:
1. В файле [user_settings.json](user_settings.json) указать интересующие валюты и акции
2. устрановить библиотеку `yfinance` с помощью ``pip install yfinance``
3. Добавить API ключ в [.env.example](.env.example) с сайта `https://apilayer.com/`

* ### Отдельная работа функций:
#### 1. Функция reading_excel_file
* Читает excel файл и заменяет пустые строки на None.
#### 2. Функция date_analiz:
* Проверяет корректность даты
* Выдает в формате MM.YYYY
* Выдает в формате DD.MM.YYYY HH:MM:SS
#### 3. Функция increased_cashback_categories:
* Принимает в качестве аргументов дату пользователя и список с транзакциями
* Фильтрует транзакции по дате 
* проверяет ключи с бонусами и кэшбэком
* Складывает выгоду в отдельные ключи
#### 4. Функция investment_bank:
* Принимает в качестве аргументов дату пользователя и список с транзакциями
* Фильтрует транзакции по дате 
* Ищет операции с тратами
* Округляет с учетом лимита 
* Считает разницу и суммирует её
#### 5. Функция simple_search:
* Переводит две категории в строку
* сравнивает запрашиваемое слово или предложение
#### 6. Функция phone_number_search:
* При помощи библиотеки re ищет совпадение по номеру телефона
* Выводит транзакции со всеми номерами телефонов в описании
#### 7. Функция search_for_individuals:
* При помощи библиотеки re ищет совпадение по имени в описании
* Выводит транзакции со всеми физ. лицами
#### 8. Функция convector_json:
* Читает формат .json
#### 9. Функция apilayer_current:
* Запрашивает API с .env 
* Перечислят валюты с файла настроек пользователя
* При ответе создает словарь 
#### 10. Функция stock_prices:
* Работает с библиотекой yfinance
* Работает с файлом пользовательских настроек
* Создает словарь
#### 11. Функция times_of_day
* Принимает уже готовый объект datetime
* Сравнивает время суток и выдает соответсвующий ответ
#### 12. Функция top_trans:
* Фильтрует операции за определенный период 
* Сортирует операции по тратам
* Создает словарь 
#### 13. Функция home_page:
* Фильтрует операции за определенный период 
* Считает расходы за 1 день до указанного времени
* Считает кэшбэк 
* добавляет данные с других функций
